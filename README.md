# 🚲 Urban Bikes - E-Commerce

Aplicación web e-commerce enfocada exclusivamente en la venta de bicicletas. Desarrollada con React y Tailwind CSS, la plataforma permite explorar el catálogo completo de bicicletas por categoría y gestionarlas mediante un panel de administración con rutas protegidas.

---

## 🚀 Tecnologías Utilizadas

* **Frontend:** React + Vite
* **Estilos:** Tailwind CSS
* **Enrutamiento:** React Router
* **Gestión de Formulario:** React Hook Form
* **Control de Estado:** React Context API (`ProductContext`, `UserContext`)
* **Despliegue:** Netlify

---

## ⚙️ Características Principales

* **Catálogo de Bicicletas:** Navegación por diferentes tipos de rodados (Mountain Bike, Ruta, Urbana, BMX) con diseño adaptativo (*responsive*).
* **Autenticación y Rutas Protegidas:** Sistema de inicio de sesión con control de acceso por roles.
* **Panel de Administración (CRUD):** 
  * Alta de nuevas bicicletas con validación de formularios.
  * Edición de especificaciones, stock y precios.
  * Eliminación de modelos del catálogo.
* **Navegación Fluida:** Interfaz optimizada para móviles y computadoras de escritorio.
